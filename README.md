# Adana City Hospital PPP Project - Monte Carlo Cost Risk Simulation

## Description
Python implementation of the Chang & Ko (2017) methodology for estimating lognormal cost variables in healthcare infrastructure PPP projects. This code performs correlated Monte Carlo simulation to quantify cost uncertainties and compute risk metrics for the Adana City Hospital PPP project in Turkey.

## Features
- Lognormal parameter estimation (μ, σ) from expert three-point estimates
- Correlated Monte Carlo simulation with 10,000 iterations
- Risk metrics: VaR, CVaR, probability of overrun
- Sensitivity analysis (correlation coefficients, variance contributions)
- Scenario analysis (optimistic, most likely, pessimistic)
- Publication-ready visualizations
